# SOSQLIK

Starter Astro pour sosqlik.fr.

## Démarrage

```bash
npm install
npm run dev
```

Puis ouvrir l'adresse locale indiquée par Astro.

## Build

```bash
npm run build
```

Le site statique est généré dans `dist/`.

## Déploiement Cloudflare

Le projet est prévu pour un déploiement statique sur Cloudflare.

- commande de build : `npm run build`
- dossier de sortie : `dist`
- domaine prévu : `sosqlik.fr`

## Structure

- `src/pages/` : pages du site
- `src/layouts/` : layout principal
- `src/components/` : header/footer
- `src/styles/global.css` : charte graphique globale
- `public/` : favicon et futurs médias
